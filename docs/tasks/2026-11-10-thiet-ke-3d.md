# Thiết kế cảnh 3D và nhân vật ngoài code
- Yêu cầu: "tôi muốn thiết kế mọi thứ liên quan đến 3d như bối cảnh, nhân vật ,..." — chọn hướng kết hợp: canvas 3D +
  file đặc tả cảnh (bố cục, kích thước, màu, ánh sáng, camera) + model .glb (trước mắt bộ CC0 có sẵn).
- Loại: thêm (quy trình + dữ liệu cảnh + nạp model) · Cỡ: lớn · Trạng thái: đang làm (3D-a xong — thiết kế 2026-11-10.2 đã áp; 3D-b sau mốc 3)

## Ý tưởng

```
phiên thiết kế (/ui-design)                         phiên code (/ui-apply)
  sửa design/scene/scene.json  ─┐
  chọn model → design/models/   ├─ npm run build:design ─► Canvas 3D (artifact: chính code web/ chạy ở chế độ xem)
  chốt → commit main            ┘                        ─► kiểm luật va chạm / vùng → npm run build → app
```

Canvas 3D **dùng lại đúng code của `web/`** (thêm một trang `design.html`), không viết một bản three.js riêng. Nhờ vậy
cái bạn xem trên canvas trùng khớp với app, không bị "canvas một kiểu, app một kiểu".

## Phạm vi
**Sẽ sửa**
- `web/src/scene/spec.ts` (mới): kiểu `SceneSpec` + hàm kiểm dữ liệu; đọc `design/scene/scene.json`.
- `web/src/scene/environment.ts`, `walls.ts`, `buildings.ts`, `trees.ts`, `well.ts`, `world.ts`: lấy số và màu từ spec
  thay vì viết thẳng.
- `web/src/scene/models.ts` (mới): nạp `.glb` bằng `GLTFLoader` (có sẵn trong gói three, chạy offline), đặt vật trang trí.
- `web/src/player/glbCharacter.ts` (mới): `Character` từ `.glb`, đi / đứng bằng `AnimationMixer`. Lỗi nạp → dùng `blockCharacter`.
- `web/src/main.ts`: truyền spec, chọn nhân vật, truyền thông số camera cho `OrbitCamera`.
- `web/design.html` + `web/src/designPreview.ts` (mới): trang xem thiết kế: camera bay tự do, bật/tắt khung va chạm và vùng.
- `web/vite.config.ts`, `web/package.json`: thêm `build:design` → `web/dist-design/`, không chép sang app. Cho Vite đọc `../design/`.
- `.claude/skills/ui-design/SKILL.md`, `.claude/skills/ui-apply/SKILL.md`, `CLAUDE.md`, `.claude/skills/lead/SKILL.md`
  (bản đồ tính năng), `.claude/skills/hoc-xa-3d-dev/` (quy tắc model: ngân sách tam giác, dung lượng, Lambert).
- `.claude/skills/hoc-xa-3d-dev/decisions/0002-thiet-ke-3d.md` (mới).
- `docs/testing/quy_tac.md`: thêm luật nhân vật dự phòng (xem giả định 4).

**Cần kiểm tra** `web/src/input/orbitCamera.ts` (thông số camera), `web/src/input/tapToMove.ts` (mặt sân),
`web/src/zones/zones.ts` (vị trí vùng phải khớp cửa nhà), `tool/check.dart` (E-CDN, E-LOP với file ngoài `web/src`),
`app/test/` (test va chạm R-VA-1 dùng toạ độ tường).

**Không đụng** `reference/`, cầu nối / Flutter, HUD và thẻ mời (vẫn theo canvas 2D hiện có), nội dung bài học.
`design/` do phiên thiết kế ghi; phiên này không tạo file nào trong đó.

## Đã quyết (người dùng, 2026-11-10)
- Làm **3D-a trước mốc 3**; 3D-b (.glb) để sau mốc 3.
- Code **đọc thẳng** `design/scene/scene.json` lúc build; `/ui-apply` là cửa kiểm luật trước khi build cho app.
- Vùng sự kiện **neo theo nhà**.
- Nhân vật: **giữ gấu khối**; `.glb` trước mắt chỉ dùng cho vật trang trí, tới khi có model gấu riêng.

## Giả định / cần quyết định (bản gốc, xem mục trên)
1. **Thứ tự mốc**: chen trước mốc 3 (cầu nối) hay để sau? Đề xuất chia hai: **3D-a** (spec cảnh + Canvas 3D + quy
   trình), **3D-b** (model .glb, vốn là mốc 5).
2. **Code đọc thẳng `design/scene/scene.json` lúc build** (đề xuất: một nguồn, không chép tay). `/ui-apply` vẫn là
   cửa kiểm: chạy test va chạm / vùng rồi mới build cho app. Phương án khác: `/ui-apply` chép sang `web/src/`
   (an toàn hơn nhưng có hai bản).
3. **Vị trí vùng sự kiện**: vùng gắn với nhà (spec ghi "vùng ở trước cửa nhà X") hay giữ toạ độ trong `zones.ts`?
   Đề xuất gắn với nhà, để dời nhà thì vùng đi theo. Dời nhà / tường là loại "luồng/luật" (chạm R-VA-1, R-VUNG-1),
   nên phải theo đúng quy trình sửa sổ.
4. **Nhân vật**: bộ CC0 không có "gấu đội mũ, áo dài". Có hai cách: chọn một nhân vật người / thú có sẵn, hoặc giữ
   gấu khối tới khi có model riêng. Luật mới đề xuất **R-NV-1**: model nạp lỗi thì dùng nhân vật khối, app không trắng màn.
5. **Khởi tạo `scene.json`**: theo đúng vai, phiên thiết kế rút số từ code ra (giống lần khởi tạo token). Code chạy
   được cả khi chưa có file: dùng giá trị mặc định bằng đúng cảnh hiện nay.
6. Ngân sách đề xuất: tổng `.glb` ≤ 3 MB, nhân vật ≤ 5k tam giác, cả cảnh ≤ 150 draw call (hiện khoảng 140:
   26+5 cây × 4, cần gộp `InstancedMesh` như TODO trong `trees.ts`). Vật liệu trong `.glb` đổi sang Lambert khi nạp.

  bố cục + vùng, có lỗi thì chặn `npm run build`. `build:design` không chặn (để Canvas 3D hiện lỗi cho phiên thiết kế).
