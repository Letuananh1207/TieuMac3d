## Phạm vi

**Sẽ sửa**
- `web/src/style.css` — token HUD C ở `:root`, viết lại chip / nút / nhãn tên / hướng dẫn / joystick / fps; thẻ
  tên khu; màn tải; dự phòng khi không có `backdrop-filter`; bỏ token HUD cũ (`ink-2`, `muted`, `hud-glass`, …).
- `web/index.html` — DOM chip (tên nơi + " · khu" màu ngọc), thẻ tên khu, màn tải, fps ẩn mặc định.
- `web/src/ui/hud.ts` — `PlaceChip` hai phần, fps chỉ khi gỡ lỗi (`?debug`); `ui/areaBanner.ts` (mới, thẻ tên
  khu); `ui/loadingScreen.ts` (mới).
- `web/src/zones/areaTracker.ts` — trả thêm khu hiện tại (tên + chữ Hán) để quyết định thẻ (R-HUD-3, thuần logic).
- `web/src/scene/spec.ts`, `scene/specCheck.ts` (nếu cần) — `site.han`, `site.areas[].han` (mặc định rỗng).
- `web/src/main.ts` — ghép thẻ tên khu, màn tải (chặn điều khiển tới khung hình đầu), fps gỡ lỗi.
- `web/src/input/joystick.ts` — chỉ nếu bán kính núm đổi (vòng 120, núm 48 → bán kính kéo theo thiết kế).
- `web/scripts/subset-han.mjs` (mới) + `package.json` script — cắt font chữ Hán; build gọi trước `vite build`.
- `app/lib/theme/app_colors.dart` — `sceneBackground` #E9EEEC (token `scene-bg`).
- `docs/testing/quy_tac.md` — thêm R-HUD-3, R-MAN-2 → tài liệu online → `--mark-synced`.

**Không đụng**: logic điều khiển (R-DIEU-1/2), va chạm, nội thất, bảng bài học (mốc 3, giữ token `ink`, `board*`).
