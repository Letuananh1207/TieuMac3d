# Hồ sơ khảo cứu (tham khảo phong cách)

Do `/khao-cuu` ghi. Là **tham khảo**, không phải thiết kế đã chốt — thiết kế chốt nằm ở `design/` (phiên thiết kế).
Phiên thiết kế đọc hồ sơ ở đây trước khi dựng khu / kiểu vật liên quan.

núi) · Hậu Sơn (thác, động bế quan) · trang phục theo bậc đệ tử · không khí tiên hiệp (sương, mây, ánh sáng).
