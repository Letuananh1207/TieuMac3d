# Nhạc nền trà lâu — nguồn và giấy phép

Mỗi file nhạc trong thư mục này phải có một dòng dưới đây. Chỉ dùng bản thu **CC0 / phạm vi công cộng** (hoặc giấy
phép cho phép đóng gói vào app, ghi rõ điều kiện). Thêm file → sửa `TRACKS` trong `web/src/zones/music.ts`
(tên file + thời lượng giây đúng bài) → `npm test && npm run build`.

| File | Bài | Nguồn (link) | Người thu / biểu diễn | Giấy phép | Thời lượng |
|---|---|---|---|---|---|
| `giu-cho.wav` | Giữ chỗ — 4 giây im lặng (tự tạo, không phải nhạc) | — | — | CC0 (tự tạo) | 0:04 |
